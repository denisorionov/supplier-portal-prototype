# Портал поставщиков

Демонстрационный прототип главной страницы внутреннего корпоративного сервиса. Текущий этап: главный экран и форма поиска.

## Просмотр

[Открыть прототип](https://denisorionov.github.io/supplier-portal-prototype/)

Сайт публикуется через существующую настройку GitHub Pages из корня ветки `main`. Сборка и зависимости не нужны.

## Поведение

- Ввод запроса, отправка кнопкой «Найти» или клавишей Enter.
- Очистка запроса кнопкой внутри поля или клавишей Escape.
- Проверка пустого запроса, состояние поиска и короткое уведомление о демонстрационном режиме.
- Изменение или очистка запроса отменяет незавершённую демонстрацию поиска.
- Результатов, таблиц, инструкций, подключения к данным и сетевых запросов поиска на этом этапе нет.

Все введённые данные остаются на странице и не сохраняются. Интерфейс адаптирован для узких экранов; предусмотрены клавиатурная навигация, доступные подписи и уменьшение анимации по системной настройке.

## Дизайн

Основа: предоставленное руководство по визуальному стилю VK. Фирменный синий `#0077FF`, белый фон, VK Sans Display Regular и Medium, выравнивание по левому краю. Простой знак портала создан для этого концепта и не является логотипом VK.

Шрифты загружаются локально. Источник файлов — [официальный сайт VK Sans](https://vksans.ru/):

- `https://vksans.ru/local/assets/fonts/display/woff/VK_Sans_Display_Regular.woff`
- `https://vksans.ru/local/assets/fonts/display/woff/VK_Sans_Display_Medium.woff`

Права на VK Sans принадлежат соответствующим правообладателям; шрифты не распространяются под отдельной открытой лицензией этого проекта.

## Файлы

- `index.html` — структура главной страницы.
- `assets/portal.css` — типографика, цвета, адаптивная сетка и состояния.
- `assets/portal.js` — поведение демонстрационного поиска.
- `assets/fonts/` — два используемых начертания VK Sans Display.

Предыдущая версия страницы доступна в истории Git. Существующий адрес GitHub Pages сохранён.
